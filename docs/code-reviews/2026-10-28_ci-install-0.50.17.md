# CI-Installationskorrektur 0.50.17

Die roten Prüfungen von Commit 7e4e7bd scheiterten schon in npm ci, bevor Lint, Unit-Tests oder Security-Prüfungen ausgeführt wurden. Prisma generate benötigte beim Laden der Konfiguration SQL_DATABASE_URL.

Der Workflow erhält global die künstliche Adresse postgresql://ci:ci@127.0.0.1:1/boardgametools_ci. Sie erlaubt Codegenerierung ohne erreichbare Datenbank und wird nicht in Vercel übernommen. Die Produktionskonfiguration und Prisma-Migrationslogik bleiben unverändert.

Ein neuer Regressionstest übernimmt die Workflow-Variablen und führt den tatsächlichen postinstall in einem temporären Verzeichnis ohne .env-Dateien aus. Vor der Korrektur scheiterte er am gemeldeten Fehler, danach besteht er. YAML 2.9 wird als direkte Entwicklungsabhängigkeit für das Lesen des Workflows deklariert; es war bereits im Lockfile vorhanden.

Lokale Prüfung: 648 Tests in 71 Dateien erfolgreich, TypeScript und ESLint erfolgreich. Zusätzlich wird npm ci mit aktivierten Installationsskripten in einer frischen Projektkopie geprüft. Die neuen Remote-Ergebnisse müssen nach Push abgewartet werden; ein erfolgreicher Vercel-Build allein belegt keine erfolgreiche CI.
