# Monatliche Prüfung von Vercel-Ausgaben

Für den am 09.11.2026 vom Nutzer bestätigten Hobby-Tarif ist kein Spend
Management konfigurierbar. Vercel pausiert Projekte beim Überschreiten der
enthaltenen Gratislimits. Diese Liste dient weiterhin der regelmäßigen
Kontrolle der Usage-Hinweise und wird nach Tarif-, Team- oder Produktänderungen
aktualisiert. Keine Rechnungen oder persönlichen Kontaktdaten in Git ablegen.

| Prüffeld | Ergebnis / Nachweis |
|---|---|
| Datum, prüfende Rolle und verifiziertes Team | Offen |
| Tarif, Abrechnungszyklus und betroffene Projekte | Offen |
| Nutzung und Kosten je Projekt/Region; aktuelle Prognose | Offen |
| Vergleich zu den letzten drei vollständigen Perioden | Offen |
| Planlimits/Usage-Hinweise aus Vercel | Im Dashboard prüfen; kein Konto-Readback im Repository |
| Health-Firewallstatus und tatsächlicher Rollout von FEAT-006 | Offen |
| Warnungen geprüft; Empfänger und Stellvertretung erreichbar | Offen |
| Verhalten oberhalb der Hobby-Kontingente | Automatische Pause laut Vercel-Plan; Projektstatus im Dashboard prüfen |
| Pause/Wiederaufnahme und verantwortliche Person | Nach einem tatsächlichen Limitereignis im Dashboard prüfen |
| Verbleibende Kosten außerhalb Spend Management | Offen |
| Abweichung, Maßnahme und nächster Prüftermin | Offen |

Ein allgemeiner Pipeline-Deploymentcheck ist kein Billing- oder Budgetnachweis.
